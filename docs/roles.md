# Распределение задач

Роли разданы по этапам конвейера: так структура кода совпадает с
структурой проекта, которую преподаватель перечислил в письме.

| Модуль | Файл | Кто | Сложность |
|--------|------|-----|-----------|
| №1 | `url_checker.py` | база, референс уже готов | низкая |
| №2 | `page_analyzer.py` | самый опытный в Python | высокая |
| №3 | `llm_judge.py` | тот, кто готов возиться с моделями | средняя |
| №4 | `synthesizer.py` | тот, кто общается с преподавателем | средняя |

## Почему так

- **Этап 1** берёт тот, кто начинает: на нём можно быстро получить
  рабочий результат и въехать в проект.
- **Этап 2** самый рискованный по времени: Selenium, ожидание загрузки,
  обходы антибот-защит. Сюда нужен тот, кто не сдастся на третьем дне.
- **Этап 3** изолирован: у него своя модель, свой промпт, своя отладка.
  Его можно вести параллельно с этапом 2, они почти не пересекаются.
- **Этап 4** ведёт человек, который пишет преподавателю: он собирает
  всё вместе и видит, чего хочет заказчик.

## Договорённости

1. **Не трогаем чужие файлы.** Каждый правит свой модуль.
2. **`models.py` — общий контракт.** Меняем только всей группой, иначе
   у всех разъедутся типы данных. Любая правка сначала обсуждается.
3. **Своя ветка + pull request.** `main` неприкосновенна.
4. **Один отвечает за окружение.** Версии в `requirements.txt` фиксирует
   и обновляет один человек, остальные ставят по нему.
5. **Сквозной прототип — в первую неделю.** Не «сначала доделаем свой
   модуль, потом соберём», а «всего три ссылки проходят от URL до
   вердикта, пусть криво».

## План по неделям

- **Неделя 1.** Общий репозиторий, `models.py`, сквозной прототип на
  трёх сохранённых страницах. Этап 1 дописан.
- **Неделя 2.** Selenium: DOM, формы, iframe. Первый настоящий разбор страницы.
- **Неделя 3.** Ollama и промпт. Этап 2 и 3 встречаются, сверяют формат
  `PageFeatures` с тем, что реально отдаёт модель.
- **Неделя 4.** Суммаризация, сравнение шаблона и LLM, тесты, README.
- **Неделя 5.** Подготовка к защите, набор тестовых примеров, замер точности.

## Общий риск

Преподаватель просил уточнить, какую LLM использовать и делать ли
суммаризацию через неё. Эти два ответа он не дал. Значит, на защите нужно
самим объяснить, почему выбран ваш вариант, и показать, что альтернативу
проверяли. Подготовьте сравнение: шаблон против LLM на одном и том же наборе
страниц, с оценкой времени ответа и повторяемости.
