# Тестовые страницы

Здесь лежат сохранённые страницы, на которых проверяется качество
детектора и стабильность ответа LLM. Файлы не загружают заново при
каждом запуске: страницы могут измениться или исчезнуть, и тогда
результаты эксперимента перестанут быть сравнимыми.

## Что сохранять

Минимум пять страниц, чтобы покрыть границы:

| Файл | Что на странице | Ожидаемый вердикт |
|------|-----------------|-------------------|
| `01_benign_login.html` | настоящая форма входа на официальном домене | benign |
| `02_benign_shop.html` | обычный интернет-магазин, форм нет | benign |
| `03_phish_credentials.html` | форма пароля, `action` на сторонний домен | phishing |
| `04_phish_brand.html` | домен имитирует известный бренд | phishing |
| `05_suspicious_frame.html` | страница с фреймворком, iframe скрыт | suspicious |

## Как сохранять

В Chrome или Firefox: «Сохранить страницу как», полный HTML со
вложенными ресурсами. Имя файла — по таблице выше.

## На что смотреть при проверке

- Ответ LLM не меняется от запуска к запуску на одной и той же странице.
  Если меняется — в промпте не хватает определённости.
- Признаки совпадают с ожидаемым вердиктом, а не просто «что-то нашлось».
- Модель не упоминает того, чего нет в словаре `PageFeatures`.

## Важно

Эти файлы используются только для локальной проверки. Публиковать
реальные страницы фишинговых сайтов не нужно и не стоит: достаточно
сохранённой разметки, а исполняемые сценарии из неё убирайте.
