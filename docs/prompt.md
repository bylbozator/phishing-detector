# Промпт для этапа 3

Черновик. Преподаватель прямо попросил промпт доработать, поэтому этот файл
и есть та задача. Правьте его командой, а не по одному.

## Что модель получает

Не сырой HTML, а словарь из `PageFeatures.to_prompt_dict()`:
URL, заголовок, формы (action, method, хост action, наличие поля пароля,
видимые поля), iframe, внешние хосты, найденные слова, относящиеся ко
входу и оплате, названия брендов, сведения о сертификате.

## Ограничения

- Вход фиксированного размера. Обрезайте длинные поля, реальные страницы
  бывают по мегабайту и модель на них отвечает мусором.
- Модель должна возвращать только JSON, иначе разбор ломается.
- Если признаков мало, модель обязана отвечать «мало данных», а не
  выдумывать. Это самый частый способ получить от LLM уверенную чушь.

## Шаблон

```text
Ты — аналитик безопасности. Ниже даны признаки веб-страницы, полученные
парсингом DOM. Определи, является ли страница фишингом.

Признаки (JSON):
{features}

Критерии:
- ФОРМА пароля отправляется на домен, отличный от домена страницы, — сильный признак.
- Скрытый iframe с внешним источником — сильный признак.
- Домен страницы имитирует известный бренд, но сам бренд не является
  основным доменом — сильный признак.
- Страница просит пароль, данные карты или код из СМС, но выглядит как
  обычный информационный сайт, — сильный признак.
- Просроченный или самоподписанный сертификат — умеренный признак.
- Есть ошибки орфографии, смешение языков, срочные требования ввести
  данные — слабый признак, сам по себе не доказывает фишинг.

Ответь ТОЛЬКО JSON без пояснений:
{"verdict": "phishing|suspicious|benign|insufficient_data",
 "score": 0-100,
 "reasons": ["краткое объяснение", ...]}

Примеры:

Признаки: {"url": "https://www.sberbank.ru/login", "title": "СберБанк — вход",
"forms": [{"action": "https://www.sberbank.ru/auth", "method": "POST",
"action_host": "www.sberbank.ru", "password_field": true, "visible_fields": ["login","password"]}],
"iframes": [], "external_hosts": [], "login_keywords": ["вход"],
"brand_names": ["sberbank"], "has_login_form": true,
"certificate": {"hostname_mismatch": false, "days_left": 200}}
Ответ: {"verdict": "benign", "score": 5, "reasons": ["домен официальный, форма отправляет данные на тот же домен"]}

Признаки: {"url": "https://sberbank.secure-login.ru/verify", "title": "Вход в СберБанк",
"forms": [{"action": "https://collector.example.net/post", "method": "POST",
"action_host": "collector.example.net", "password_field": true, "visible_fields": ["phone","password"]}],
"iframes": [{"src": "https://collector.example.net/f", "host": "collector.example.net", "hidden": true}],
"external_hosts": ["collector.example.net"], "login_keywords": ["вход","пароль"],
"brand_names": ["sberbank"], "has_login_form": true,
"certificate": {"hostname_mismatch": true, "days_left": -3}}
Ответ: {"verdict": "phishing", "score": 95, "reasons": ["домен имитирует СберБанк, но не является им", "форма пароля отправляется на сторонний домен", "скрытый iframe на внешний домен", "сертификат просрочен"]}
```

## Что проверить перед сдачей

- На двух-трёх страницах из `docs/` ответ стабилен, а не меняется от запуска к запуску.
- Признаки формулируются как в примерах: сначала суть, без воды.
- Модель не выдумывает то, чего нет в словаре.
- `score` согласован с `verdict` (benign — низкий, phishing — высокий).
